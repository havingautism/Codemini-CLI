# 01 — 数据地基：会话统计累加器 + 快照字段扩展

**What to build:** 运行时状态快照新增五组字段，并新增一个随会话存活的统计累加器。这一层用户不可见，但它让状态栏每个指标都有数据可读。快照产出：时间戳、按类型的工具计数、todo 计数、最近 3 条错误摘要、9 项系统环境信息；累加器在工具结束/失败/被拦截时累加「按类型计数」与「有界错误摘要」，随会话存活（上下文压缩后仍保留）、随会话切换重置。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [x] 快照能产出五组字段：时间戳、工具计数（按类型）、todo 计数、错误摘要（最近 3 条）、系统环境（9 项）。
- [x] 累加器对成功/失败/被拦截的工具执行正确累加。
