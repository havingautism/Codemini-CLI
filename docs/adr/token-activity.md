# Token 活动记录

空会话页面显示最近一年的 Token 热力图，支持每天 / 每周聚合；累计总量包含全部已记录时间。数据来自本机所有 CLI 和 Web UI 会话，包括子代理、fork 和辅助模型调用，按浏览器时区显示日期。

Provider 统一入口在每次调用返回后记录一次服务端报告的用量，存入全局 SQLite 的 `token_usage_records` 表。记录包含时间、模型、Provider、输入、输出、缓存读取和缓存写入 Token，不存储提示词或密钥。该表不依赖会话外键，删除或压缩会话不会清除统计。输入 Token 包含缓存读取和写入；缓存值是输入的细分，不再次加到总量。

记录从更新启用后开始，旧会话不回填：其时间和完整调用明细未必可恢复，复制 / fork 的消息也可能产生重复统计。Provider 未返回用量的调用单独计数，不估算成 Token。失败或中断并抛出错误的请求目前没有完成用量可记录，因此这些数据不是服务商账单；也不包含绕过统一 Provider 入口的外部请求。

`GET /api/usage/activity?timeZone=Asia%2FShanghai` 返回日期范围、每日输入 / 输出 / 总量 / 请求数 / 未报告用量请求数和累计统计。空页面每分钟和重新显示页面时刷新。未来扩展模型和项目统计时，可在独立记录上增加查询，不依赖会话列表。
